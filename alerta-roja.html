Proyecto académico independiente

Alerta Roja

Una plataforma móvil y web para registrar, gestionar y atender emergencias reportadas por ciudadanos.

La solución conecta ciudadanos, bomberos y administradores para agilizar el reporte de incidentes, compartir la ubicación mediante GPS y adjuntar evidencia fotográfica.

Descargar APK Ver código en GitHub

Disponible para Android. La descarga se abre de forma segura en Google Drive.

Funcionalidades

Una solución diseñada para cada rol

📍

Ciudadanos

Registran emergencias, comparten su ubicación y adjuntan evidencia fotográfica desde la aplicación.

🚒

Bomberos

Consultan y dan seguimiento a los incidentes para priorizar la atención de emergencias.

🛡️

Administración

Gestiona usuarios, alertas e información del sistema desde un panel centralizado.

Tecnología

Arquitectura del proyecto

Aplicación multiplataforma con una API para centralizar la gestión de datos, autenticación y reportes.

  • Flutter / Dart
  • Node.js / Express
  • MySQL
  • JWT
  • APIs REST
  • Geolocalización GPS
